Git Command Cheat Sheet

Check Git Version
git --version
Purpose: Check the omstalled Git version.

Configure Username
git config --global user.name"Hlaing Hlaing Nay Myo"
Purpose: Set your Git username.

Configure Email
git config --global user.email "hlainghlaingnm@gmaul.com"
Purpose: Set your Git email address.

Display Configuration
git config --list
Purpose: Show Git configuration information.

Clone Repository
git clome repository-url
Purpose: Download a GitHub repository.

Check Status
git status
Purpose: Add all modified files to staging.

Commit Changes
git commit -m "message"
Purpose: Save changes locally.

Upload to GitHub
git push
Purpose: Upload local commits to GitHub.

Download Updates
git pull
Purpose: Download changes from GitHub.

View Commit History
git log --oneline
Purpose: Display project history.

Create Branch
git branch branch-name
Purpose: Change to another branch.

Merge Branch
git merge branch-name
Purpose: Merge another branch into current branch.
